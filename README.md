This is a make.fun entry: one line of wedding vows for a robot couple. It takes the classic vow — "in sickness and in health" — and makes the promise machine-specific: whatever crashes, whatever resets, the vow is to bring the other one back from backup.

## The vow

```
In sickness and in health, in firmware updates and factory resets, I will always restore you from backup.
```

## How it works

The program (`main.ts`, Node 22) writes the vow to `/output/entry.txt` (105 characters, inside the 1–160 gate).
